# ВИРАЛ — Симулятор блогера (`Simul Native C++20`)

100% нативная игра и специализированный Data-Oriented C++20 движок **`Simul Native`**, созданные специально под механики **«ВИРАЛ — симулятор блогера»** — без WebView, без браузерных обёрток и без тяжёлых сторонних движков.

## Главные особенности

- **Чистый нативный C++20 код под телефоны и ПК**:
  - **Android (`.apk`)**: `android.app.NativeActivity` (`hasCode="false"` — 0 байт Java/WebView), **OpenGL ES 3.0**, **AAudio**, поддержка тач-жестов и инерционного скролла. Вес `.apk` — **~1.5 МБ**.
  - **Windows (`.exe`)**: **Win32 + Direct3D 11 + WASAPI + WinHTTP**, статическая линковка CRT (один автономный `.exe` файл весом **~1 МБ**, запускается сразу без установки DLL).
  - **Linux / macOS**: X11 + OpenGL 3.3 + ALSA / Cocoa + Metal.
- **Экстремальная производительность (`AudiencePool` SoA)**:
  - **100 000 живых микро-агентов аудитории** занимают всего **2.38 МБ ОЗУ** (`alignas(64)` SIMD-массивы).
  - Расчёт одной часовой волны рекомендаций на 100 000 зрителях занимает **~170 микросекунд** (~5 800 волн/сек на одном ядре CPU).
- **Честная физика алгоритма рекомендаций**:
  - 5 волн продвижения (10% ядра → ядро → смежные интересы → широкая лента → виральный взрыв),
  - A/B сплит-тестирование двух вариантов обложек и заголовков,
  - Скрытый рейтинг доверия (`trust_score`), шадоубан и смена эпох алгоритма,
  - Подробный русскоязычный **Пост-Мортем разбор** каждого ролика.
- **1 GPU Draw Call на весь кадр + процедурный звук**:
  - Встроенный кириллический шрифт `GolosText` (UTF-8 растрирование через `stb_truetype`), графики волн 48ч, кривые удержания, частицы и тактильный процедурный аудио-синтезатор.
- **Асинхронный общий мир (`Supabase`)**:
  - Общий пул показов по нишам и сезонные таблицы лидеров (`supabase/migrations/0001_simul_async_world.sql`) с бесшовным офлайн-режимом и бинарными сохранениями `.simsave` (CRC32).

## Автосборка `.apk` и `.exe` (GitHub Actions)

В репозитории настроен конвейер [`.github/workflows/build-native.yml`](.github/workflows/build-native.yml), который при каждом пуше и Pull Request автоматически:
1. Прогоняет модульные C++20 тесты (включая headless-проверку GPU-рендера и кириллического атласа) и стресс-бенчмарк на 100 000 агентах;
2. Компилирует автономный **`ViralSimul-Windows-x64.exe`** (Direct3D 11, x64);
3. Кросс-компилирует через Android NDK и подписывает готовый к установке на смартфон **`ViralSimul-Android-arm64.apk`** (`arm64-v8a`, Android 8.0+).

Готовые артефакты доступны для скачивания на вкладке **Actions** последнего сборочного прогона.

## Быстрая локальная сборка

### Запуск C++20 автотестов и стресс-бенчмарка 100 000 агентов (GCC / Clang + Make)
```bash
make test
make bench
```

### Сборка через CMake (Windows / Linux / macOS)
```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release --parallel
```
