# Simul Engine & «ВИРАЛ» (v0.1.0)

**`Simul`** — специализированный высокопроизводительный 2D-движок для системных и менеджмент-симуляторов с агентным моделированием живой аудитории, честной математикой алгоритмов и асинхронным мультиплеером. Разработан специально под игру **«ВИРАЛ — симулятор блогера»**.

---

## Ключевые возможности движка `Simul`

- **Data-Oriented SoA ядро (`@simul/core`):** десятки тысяч «живых» зрителей хранятся в непрерывных `TypedArray`-буферах (`Float32Array`, `Uint8Array`, `Uint16Array`) без мусора для GC. Один 48-часовой волновой цикл на `25 000` агентах просчитывается за считанные миллисекунды.
- **Строгий детерминизм (`Xoshiro128**`):** бит-в-бит воспроизводимость карьеры по `seed` на клиенте (Android / iOS / ПК / Web) и на сервере (Supabase Edge Functions для защиты от читов).
- **Живой многоволновой алгоритм рекомендаций:** 5 волн показов (`Wave 0..4`), учёт CTR, удержания по децилям, скорости реакций, A/B-тест обложек, смена эпох алгоритма и индекс доверия канала (шадоубан).
- **Нарративные дилеммы с отложенными последствиями:** бинарная куча событий `SimulationClock` возвращает последствия сомнительных интеграций, конфликтов и смены ниши спустя недели и месяцы.
- **Собственный 2D-рендер и процедурный звук (`@simul/renderer`):** High-DPI Canvas 2D графики реального времени, частицы прорыва в тренды, пружинная физика `SpringValue` и синтезатор звуков на `WebAudio API` без тяжёлых аудиофайлов.
- **Асинхронный общий мир (`@simul/cloud` + Supabase):** единый пул показов по нишам (вирусный хит соперника сжимает свободный охват), сезонные рейтинги и облачные снапшоты с автоматическим локальным фоллбэком (`LocalWorldAdapter`).

## Быстрый старт

```bash
# Установка зависимостей монорепозитория
npm install

# Проверка строгой типизации всех пакетов
npm run typecheck

# Запуск автотестов и бенчмарка ядра
npm test

# Запуск интерактивной лаборатории движка Simul Studio
npm run dev

# Продакшн-сборка пакетов и веб-стенда
npm run build
```

### Подключение боевого мира Supabase

1. Примените миграцию [`supabase/migrations/0001_simul_async_world.sql`](supabase/migrations/0001_simul_async_world.sql) в вашем проекте Supabase.
2. Скопируйте `.env.example` в `.env.local` и укажите `VITE_SUPABASE_URL` и `VITE_SUPABASE_PUBLISHABLE_KEY`.
3. Без `.env.local` движок автоматически запускается в `LocalWorldAdapter` с симуляцией ИИ-конкурентов в общем пуле показов.
