# План реализации нативного движка и игры «ВИРАЛ» (`Simul Native`)

Документ фиксирует этапы разработки 100% нативной игры (C++20, Android `.apk` + Windows `.exe`).

---

## Этап 1. Архитектура и нативное ядро симуляции `simul::core` — ВЫПОЛНЕНО
- [x] Полный отказ от веб-обёрток (TypeScript / HTML5 / WebView) в пользу чистого нативного `C++20`.
- [x] Детерминированный генератор `Xoshiro128**`, физические пружины `SpringValue`, игровые часы `SimulationClock` с очередью отложенных последствий.
- [x] Выровненный по кэш-линии (`alignas(64)`) SoA-пул живых зрителей `AudiencePool` (5 сегментов, усталость, выгорание к рекламе, старение, ностальгия «олдов» при смене ниши).
- [x] Пятиволновой рекомендательный алгоритм `RecommendationEngine` (Волны 0..4, A/B-тест обложек, траст и шадоубан, смена эпох алгоритма, русскоязычный Пост-Мортем разбор).
- [x] Математические решатели мини-игр (монтаж, превью/заголовок, живой стрим), система трендов, дилемм, команды/выгорания и генератор комментариев.
- [x] Бинарная система сохранений `BinarySave` (`.simsave`) с контрольной суммой `CRC32`.
- [x] Нагрузочный бенчмарк на **100 000 живых агентов**: `2.38 МБ` ОЗУ, `~170 мкс` на часовую волну.

## Этап 2. Нативный GPU-рендерер, звук и клиент игры «ВИРАЛ» — ВЫПОЛНЕНО
- [x] Нативные системные бэкенды `Sokol`:
  - **Windows `.exe`**: Win32 + Direct3D 11 + WASAPI + WinHTTP (статическая линковка CRT без внешних DLL).
  - **Android `.apk`**: `android.app.NativeActivity` (`hasCode="false"`) + OpenGL ES 3.0 + AAudio.
  - **Linux / macOS**: X11 + OpenGL 3.3 + ALSA / Cocoa + Metal + AudioToolbox.
- [x] Кириллический UTF-8 глиф-атлас (`GolosText` + `stb_truetype`) и однопроходный батч-рендерер `Renderer2D` (карточки, графики 48ч, кривые удержания, частицы за 1 GPU draw call).
- [x] Процедурный lock-free синтезатор звука `NativeSoundSynth` (тактильные отклики, аккорды пробития волн, звук монет, сигнал тревоги).
- [x] Адаптивный портретно-десктопный игровой интерфейс `ViralGameApp` (5 вкладок: *Студия*, *Алгоритм*, *Аудитория*, *Карьера*, *Мир* + инерционный тач-скролл).
- [x] Облачная схема `supabase/migrations/0001_simul_async_world.sql` и клиент `WorldSyncService`.

## Этап 3. Автоматическая CI/CD сборка `.apk` и `.exe` — ВЫПОЛНЕНО
- [x] GitHub Actions пайплайн `.github/workflows/build-native.yml`:
  - Автопрогон C++20 юнит-тестов и 100k SoA бенчмарка,
  - Автосборка автономного **Windows x64 `.exe`** (`ViralSimul-Windows-x64.exe`),
  - Автосборка подписанного **Android ARM64 `.apk`** (`ViralSimul-Android-arm64.apk`, `apksigner` v1+v2+v3).

## Этап 4. Следующие итерации доработки игры (Roadmap v0.3 – v1.0)
1. **Интерактивные визуальные сцены мини-игр (v0.3)**:
   - Полноценный таймлайн нелинейного монтажа с перетаскиванием клипов пальцем/мышью, склейкой звуковой волны и визуальными маркерами просадок внимания;
   - Конструктор обложки (слои фона, эмоции персонажа, плашки текста, предпросмотр на светлой/тёмной ленте смартфона).
2. **Визуальная эволюция студии блогера (v0.4)**:
   - Изометрическая/2.5D сцена комнаты в шапке экрана *Студия*, меняющаяся от спальни со старым ноутбуком до неонового продакшн-павильона с командой в кадре.
3. **Расширенный контент и сюжетные арки (v0.5)**:
   - 60+ ветвящихся нарративных дилемм, коллаборации с другими каналами, бифы, премии и переход в собственную медиа-империю (Этапы 4–5).
4. **Полный Android HTTPS NDK сокет/TLS транспорт и релизные подписи (v0.6)**:
   - Подключение нативного TLS-клиента на Android к боевому проекту Supabase + публикация автоматических GitHub Releases с готовыми `.apk` и `.exe` по тегам версий.
