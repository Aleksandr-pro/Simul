# План реализации нативного движка и игры «ВИРАЛ» (`Simul Native`)

Документ фиксирует этапы разработки 100% нативной игры (C++20, Android `.apk` + Windows `.exe`).

---

## Этап 1. Архитектура и нативное ядро симуляции `simul::core` — ВЫПОЛНЕНО
- [x] Полный отказ от веб-обёрток (TypeScript / HTML5 / WebView) в пользу чистого нативного `C++20`.
- [x] Детерминированный генератор `Xoshiro128**`, физические пружины `SpringValue`, игровые часы `SimulationClock` с очередью отложенных последствий.
- [x] Выровненный по кэш-линии (`alignas(64)`) SoA-пул живых зрителей `AudiencePool` (5 сегментов, усталость, выгорание к рекламе, старение, ностальгия «олдов» при смене ниши).
- [x] Пятиволновой рекомендательный алгоритм `RecommendationEngine` (Волны 0..4, A/B-тест обложек, траст и шадоубан, смена эпох алгоритма, русскоязычный Пост-Мортем разбор).
- [x] Бинарная система сохранений `BinarySave` (`.simsave`) с контрольной суммой `CRC32`.
- [x] Нагрузочный бенчмарк на **100 000 живых агентов**: `2.38 МБ` ОЗУ, `~165 мкс` на часовую волну.

## Этап 2. Нативный GPU-рендерер, звук и автосборка `.apk` / `.exe` — ВЫПОЛНЕНО
- [x] Нативные бэкенды `Sokol` (Windows Direct3D 11 + WASAPI + WinHTTP; Android `NativeActivity` OpenGL ES 3.0 + AAudio; Linux/macOS).
- [x] Процедурный lock-free синтезатор звука `NativeSoundSynth`.
- [x] Облачная схема `supabase/migrations/0001_simul_async_world.sql` и клиент `WorldSyncService`.
- [x] GitHub Actions автосборка `ViralSimul-Windows-x64.exe` и `ViralSimul-Android-arm64.apk` с прямой выкладкой в GitHub Releases (`latest`).

## Этап 3 (v0.3). Адаптация дизайна под смартфоны + Живая Студия и Мини-Игры — ВЫПОЛНЕНО
- [x] **Честный расчёт физической плотности `dp` экрана смартфона (`AConfiguration_getDensity`)**: портретная сетка `360..425 dp` с крупными touch-кнопками (`42–52 dp`) под большой палец вместо мелкого масштаба сырых пикселей `1080×2400`.
- [x] **High-DPI кириллический атлас `2048×2048` (`56px`)**: бритвенно-чёткие русские шрифты на OLED-дисплеях 3x/4x и мониторах 4K.
- [x] **Полноэкранный режим без чёрных полос (`shortEdges` cutout) и Safe-Area отступы**: защита верхней шапки от селфи-камеры и нижнего таб-бара от жестовой полосы Android + защита от сквозных нажатий при скролле и разделение жестов слайдера/скролла.
- [x] **Автосохранение карьеры (`internalDataPath`)**: мгновенное сохранение прогресса при каждом действии и при сворачивании игры на телефоне (`SAPP_EVENTTYPE_SUSPENDED`).
- [x] **Живая 2D-иллюстрация комнаты-студии блогера (`studio_scene.cpp`)**: визуальная эволюция от ночной спальни с ноутбуком до неонового павильона 4K с двумя мониторами, кольцевым светом, кинокамерой и нанятыми сотрудниками в кадре.
- [x] **Интерактивная мини-игра «Таймлайн монтажа»**: 8 звуковых клипов с ручной резкой «воды» и усилением ключевых сцен (`⚡ SFX + Зум`), выбором позиции рекламной интеграции и кнопкой «Авто-монтаж».
- [x] **Визуальный конструктор превью `16:9` (A/B сплит-тест)**: настройка цветовой схемы, фокусной композиции кадра, текстовой плашки и кликбейта с живым предпросмотром карточки в мобильной ленте.
