# РАЗЛОМ — сетевой протокол (v1)

Транспорт: **TCP**. Кадр: `u32 длина` (в *сетевом* порядке — big-endian), затем `u8 тип`, затем payload. Все числа внутри payload — little-endian. Максимальный кадр — 1 МБ, всё большее считается ошибкой и рвёт соединение. Порт по умолчанию — **47800**, клиент при создании мира сам ищет свободный порт в диапазоне 47800–47807.

```
[4 байта длины][1 байт типа][payload ...]
```

`kProtocolVersion = 1` (`include/razlom/net/protocol.hpp`). Несовпадение версии — сервер отвечает `Disconnect` с причиной и закрывает сокет.

## Клиент → сервер

| Код | Пакет | Payload |
|---|---|---|
| 1 | `Hello` | `u16 version`, `string name`, `u8 color`, `u32 protocolHash` |
| 2 | `Input` | `u32 tick`, `f32 yaw`, `f32 pitch`, `u8 flags`, `f32 posX/Y/Z` (для сверки) |
| 3 | `EditRequest` | `u32 tick`, `u8 action` (0 — ломать, 1 — ставить), `i32 x,y,z`, `u8 block` |
| 4 | `ChatRequest` | `string text` |
| 5 | `Attack` | `u32 tick`, `u32 targetId` |
| 6 | `ExplodeRequest` | `u32 tick`, `i32 x,y,z` |
| 7 | `RespawnRequest` | `u32 tick` |
| 8 | `Ping` | `u32 tick` |
| 9 | `Leave` | — |

`Input` шлётся с частотой **20 Гц** (каждый тик). `Ping` — раз в секунду для оценки задержки. `flags`: бит 0 — прыжок, 1 — присед, 2 — полёт, 3 — спринт, 4 — ломаю, 5 — ставлю.

## Сервер → клиент

| Код | Пакет | Payload |
|---|---|---|
| 16 | `Welcome` | `u32 playerId`, `u32 seed`, `u16 tickRate`, `u8 mode`, `string roomCode`, `u32 historySize` + записи `i32 x,y,z; u8 block` |
| 17 | `Reject` | `u8 reason` |
| 18 | `Snapshot` | `u32 tick`, `u16 count` + игроки: `u32 id`, `u8 color`, `f32 x,y,z`, `f32 yaw`, `f32 pitch`, `u16 health`, `u8 flags`, `string name` |
| 19 | `BlockChanged` | `i32 x,y,z`, `u8 block`, `u8 cause` (0 — игрок, 1 — обрушение, 2 — взрыв, 3 — огонь, 4 — вода, 5 — восстановление) |
| 20 | `DebrisSpawn` / `DebrisUpdate` | `u16 count`, для каждого: `u32 id`, `i32 x,y,z`, `f32 px,py,pz`, `f32 vx,vy,vz`, `u8 block` |
| 21 | `Event` | `u8 kind` (0 — взрыв, 1 — обрушение, 2 — смерть, 3 — респавн, 4 — разлом), `f32 x,y,z`, `f32 radius`, `u32 actorId` |
| 22 | `ChatMessage` | `u32 senderId`, `string name`, `string text` |
| 23 | `Pong` | `u32 tick`, `u32 serverTick` |
| 24 | `Disconnect` | `string reason` |
| 25 | `ModeChanged` | `u8 mode`, `string title` |

Снимок игроков — **20 Гц**, вместе с тиком симуляции; правки блоков и события — немедленно, списком за тик (дедупликация по индексу блока).

## Вход по ссылке

Ссылка: `razlom://<host>:<port>/<CODE>`, где `<CODE>` — 4 символа из `ABCDEFGHJKLMNPQRSTUVWXYZ23456789` (без похожих `I/O/0/1`). Парсер принимает:

- `razlom://192.168.1.10:47800/QK7M`
- `192.168.1.10:47800`
- `QK7M` (в локальной сети хост ищет по широковещательному обнаружению — этап 2, пока требуется адрес)

`Client::joinLink` нормализует вход и подставляет порт по умолчанию.

## Валидация и авторитет

Сервер авторитетен по всему, что влияет на мир:

- **Действия** — не дальше 6 блоков от позиции игрока, кулдаун ломания/установки, блок должен быть разрушаемым/устанавливаемым в пустое место.
- **Взрыв** — не чаще, чем режим разрешает; радиус и урон считает сервер.
- **Позиция** — сервер не «тепепортирует» клиента к своей позиции, но сверяет её с последней (рывок > 40 блоков за тик = отказ и сброс к серверной позиции при следующем тике).
- **PvP** — только в режимах с `pvp = true`, урон начисляет сервер (24 за удар, 78 в эпицентре взрыва), смерть → 3.5 с до респавна.

Игроки с `health == 0` не могут ставить блоки и получать урон повторно.

## Мир по сети

Мир не передаётся целиком: `Welcome` отдаёт `seed` и историю правок (лимит 150 000 записей, дедуплицированных по индексу блока). Клиент генерирует мир локально тем же детерминированным генератором и накладывает правки. Это даёт вход за секунды даже на мобильном интернете.

## Надёжность

TCP гарантирует доставку, но не порядок между потоками клиента — читающий поток складывает пакеты в inbox под мьютексом, приложение разбирает их по одному в кадре. Неизвестный тип пакета логируется и пропускается (совместимость вперёд). Отключение — `shutdownBoth()` перед `close()`, чтобы поток чтения не висел на блокирующем `recv`.

## Ограничения v1

- Нет ретранслятора и NAT-punch: игра по ссылке — в одной сети или с проброшенным портом.
- Нет шифрования и аутентификации: любой, кто знает код, заходит в мир.
- Нет дельты-сжатия снимков: 20 Гц × 4 игрока ≈ 2 КБ/с.
